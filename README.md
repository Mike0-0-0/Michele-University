# Michele's University Portfolio

A collection of scientific programming projects and academic works developed during my Physics studies at Tor Vergata University.

## Projects Overview
* **[Sea-Breeze Detection Algorithm](breeze-algorithm/)**: Python script utilizing multi-proxy meteorological data (wind speed, direction, solar radiation, and precipitation) to identify and analyze sea-breeze days over Rome.
* **[Tokamak Diffusion Simulation (B.Sc. Thesis)](tokamak-thesis/)**: 1-dimensional cellular automaton modeling plasma confinement and self-organized criticality (SOC) in the L-mode regime, structured across core simulation stages and statistical scaling analyses.
